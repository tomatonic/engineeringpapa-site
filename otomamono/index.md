# オトマモノ

あなたが聴いてきた曲には、もうモンスターが宿っています。

端末のミュージックライブラリにある曲からモンスターを見つけて、図鑑に集めていく iOS アプリです。

## コンセプト

**同じ曲からは、いつ・誰の端末で召喚しても、必ず同じモンスターが生まれます。**

モンスターは曲名とアーティスト名から計算で決まります。だから「この曲からはこれが出た」を人と見せ合えるし、あなたの図鑑は、あなたがこれまで聴いてきた音楽そのものの形になります。

集めるとは、聴いてきた曲のモンスターを一体ずつ形にして並べていく行為です。

## 主な機能

- 端末の曲からモンスターを召喚（無料・回数制限なし・広告なし）
- 12種族 × 10マス、計120マスの図鑑
- レア度 N / R / SR / SSR と、6色のカラーバリエーション
- 召喚したモンスターを画像で共有
- データはすべて端末内のみに保存（サーバー送信なし・通信なし）

## 読み取る情報について

読み取るのは曲名・アーティスト名・アルバム名・再生時間・ジャンル・リリース年・トラック番号だけです。
**音源そのもの（音声データ）には触れません。** 再生も録音もコピーもしません。

ミュージックライブラリへのアクセスを許可しない場合でも、図鑑の閲覧はできます。
